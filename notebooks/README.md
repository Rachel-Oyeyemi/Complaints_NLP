# Notebook Plan

Use this folder for notebook-based exploration and storytelling.

Recommended notebooks:

1. `01_data_exploration.ipynb` - dataset overview, missing values, product distribution, company trends.
2. `02_text_preprocessing.ipynb` - text cleaning examples and narrative length analysis.
3. `03_model_training.ipynb` - TF-IDF model training and evaluation.
4. `04_topic_modeling.ipynb` - LDA or BERTopic complaint theme discovery.
5. `05_business_recommendations.ipynb` - summary of insights and recommended next actions.

Large notebook outputs should be cleared before committing to GitHub.
